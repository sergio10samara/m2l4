# TextAnalysis

`TextAnalysis` — учебный проект на Python для обработки текстовых сообщений. Он переводит сообщения с русского на английский, отвечает на знакомые вопросы и хранит историю сообщений по пользователям.

## Установка

Установите библиотеку для перевода.
```bash
pip install translate
pip install pyTelegramBotAPI
```
